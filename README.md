## First task after tool foundations

Use a clearly labelled fictional example of 12 successful serves out of 20 attempts. Calculate the success proportion, check that it equals 0.60, and write three English sentences explaining the numerator, denominator, and why this toy example says nothing about a real athlete. Then change the counts and check the result by hand. Handle a zero-attempt case explicitly.

This is a planned exercise; no result file has been created yet.

## Completion standard

Each exercise should state its question, input source, how to run or reproduce it, one manual check, and what I learned. If code is added, document its Python version and any dependencies at that time. There is currently no software to install or execute.

Suggested commit style: describe the meaningful change, such as `Explain serve success proportion and check a toy example`.
